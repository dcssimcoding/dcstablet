# Glossary

This guide uses one term for each item.
Labels in bold agree with the application's labels when applicable.

| Term | Meaning |
| --- | --- |
| Application folder | The folder that contains `dcs-tablet.exe` and the command files. |
| Build date | The UTC date recorded when the developer builds the application file. |
| Build ID | A value that identifies the application's build inputs. It is not a security signature. |
| Command | A line of text that tells PowerShell or an application to do a task. |
| Command file | A file such as `Start-Demo.cmd` that starts a prepared command. |
| Console | The text window that shows application messages. |
| Controller settings | DCS assignments for your keyboard, joystick, and other controls. |
| DCS profile | A folder that contains one set of DCS settings and user files. |
| DCS.Tablet | The separate DCS profile that DCS Tablet creates. |
| DDI | Digital Display Indicator. The F/A-18C has a left DDI and a right DDI. |
| Demo | Colored test displays that operate without DCS World. |
| Driver | Software that lets Windows use a device, including a virtual display. |
| F-18 | In this guide, the DCS F/A-18C Hornet. |
| File record | The list of files that DCS Tablet creates in its profile. |
| Firewall | Windows protection that controls network access to applications. |
| HDR | High Dynamic Range. Keep this display option off for the virtual display. |
| HTTP | The connection type used for the application page and control messages. |
| IP address | A device's network address. An IPv4 example is `192.168.1.20`. |
| Landscape | A tablet position with the long side horizontal. |
| Main display | The monitor that Windows identifies as the main display. |
| Port | A number that selects a network service. DCS Tablet normally uses 8090. |
| PowerShell | A Windows application that accepts text commands. |
| Private network | A local network with devices and users that you trust. |
| Source profile | Your existing DCS profile from which setup copies initial settings. |
| UTC | A common time reference used for the build date. |
| Viewer | The connected browser that receives the DDI images. |
| Virtual display | An extra Windows screen without a physical monitor. |
| WebRTC | The browser video connection. It encrypts the video traffic. |
| ZIP | A package file that holds the application files together. |
